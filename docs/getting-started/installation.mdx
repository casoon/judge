## Optional features

| Feature   | What it adds                                                              | Install                                         |
| --------- | ------------------------------------------------------------------------- | ----------------------------------------------- |
| `deep`    | rust-analyzer-based Deep Tier: `dead-code`, `explain --why-live`           | `cargo install cargo-judge --features deep`     |
| `network` | crates.io lookups for `deps --check-crates-io`                            | `cargo install cargo-judge --features network`  |

<Callout type="caution">
  The `deep` feature compiles the `ra_ap_*` rust-analyzer crates. The first build takes
  noticeably longer than the default build.
</Callout>

Without `network`, no HTTP client is compiled in. `deps --check-crates-io` then skips the
crates.io checks and lists an error for each, stating that the binary was compiled without the
feature.

## Verify the install

```sh
cargo judge --version
cargo judge inspect   # crates, entry points and available tiers
```

`inspect` lists the detected crates and entry points and whether the Deep Tier is available in
this build.
